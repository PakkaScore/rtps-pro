WHAT IT DOES

Fills the form.
Saves the time.

Every field that repeats across certificate applications — RTPS Pro handles it. You only touch photo, captcha, and Submit.

⚡

One-tap auto-fill

20–30 boxes filled in seconds — text fields, radio buttons, and cascading dropdowns (State → District → Block → Panchayat) in correct sequence, waited for via MutationObserver.

👥

Multiple profiles

One profile per family member or client. Searchable by name, district or block. Duplicate, edit, rename or delete right from the profile card.

🛡️

Identity guard

Before updating a profile, RTPS Pro compares the applicant name on the page with the selected profile. Overwriting the wrong profile needs a deliberate second tap.

💾

Draft recovery

Auto-saves as you type. Session timeout or accidental refresh? One tap to restore everything — drafts kept for 7 days, then cleared automatically.

📊

Mandatory-field counter

Live "24 filled • 21 required • 3 optional" in the header. Green ★ when all required fields are done — with the missing ones listed so nothing slips through.

🔒

Export / Import backup

Back up one profile or all to a JSON file. Restore after a browser data clear or transfer to another device — no cloud account required.

GETTING STARTED

Three steps, then you're done

Install once. Save once. Auto-fill every time after.

1

Install the extension

Add from Firefox Add-ons or Edge Add-ons in one tap — auto-updates included. On Chrome, download the zip and load unpacked. Two example profiles come pre-installed to try right away.

2

Fill once, save before Submit

Open any RTPS form and fill it with real details. Before pressing Submit — open RTPS Pro → New profile → name it → Save from this form. Then submit normally.

3

One-tap from now on

Open the form → pick the profile → tap Auto-fill. Only photo, captcha and Submit remain. Every future certificate application — same one tap.

FAQ

Common questions

Is RTPS Pro free? ▾
Always. No subscription, no account, no payment. Real extension only on Firefox Add-ons (), Edge Add-ons & this GitHub repo — anyone asking money is a fake copy.
Is my personal data safe? ▾
All profiles, drafts, settings live in chrome.storage.local only. No server, no analytics, no network requests. Host access only to serviceonline.bihar.gov.in. Uninstall removes everything.
Does it press Submit automatically? ▾
No. Fills fields only. You review, attach photo, solve captcha, press Submit yourself. Declaration checkbox is never auto-ticked. Nothing submits without your action.
Does it work on Android phones? ▾
Yes. Firefox (recommended) and Edge on Android support extensions natively from official stores with auto-updates. Quetta and Kiwi also work from zip. Android Chrome doesn't support extensions.
What is the difference between OBC-NCL (Form-VI) and NCL (Form-IX)? ▾
OBC-NCL (Form-VI) is Govt. of India for central jobs — UPSC, SSC, Railways, central universities. NCL (Form-IX) is Govt. of Bihar for state jobs — BPSC, Bihar state exams. BC/EBC typically need both. RTPS Pro handles both.
Why does Chrome say "Your connection is not private" on the portal? ▾
Portal's certificate chain sometimes not trusted by Chrome/Edge on Android (NET::ERR_CERT_AUTHORITY_INVALID). Firefox opens same site without warning — portal's own compatible-browsers note recommends Firefox.
What happens if the RTPS portal layout changes? ▾
Matches fields by text labels in Hindi and English — not by fixed position or ID. Resilient to layout changes. New fields added by portal are picked up automatically on next Save, no extension update needed.
